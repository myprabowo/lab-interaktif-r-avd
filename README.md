# Lab Interaktif R

**Praktikum Analisis dan Visualisasi Data dengan Quarto**

Repositori ini berisi rangkaian **praktikum R interaktif** yang dirancang menggunakan **Quarto**.

🔗 **Versi web (Quarto Pub):**\
https://muhammadyogaprabowo.quarto.pub/lab-interaktif-r

------------------------------------------------------------------------

## 🎯 Tujuan Pembelajaran

Setelah menyelesaikan seluruh rangkaian praktikum, peserta diharapkan mampu:

-   Menggunakan R untuk eksplorasi dan analisis data
-   Memahami transformasi data dan dampaknya terhadap analisis
-   Menangani data hilang secara metodologis
-   Melakukan analisis regresi secara eksploratif dan interpretatif

------------------------------------------------------------------------

## 📂 Struktur Praktikum

| Praktikum    | Topik                        | Fokus Utama                  |
|--------------|------------------------------|------------------------------|
| Praktikum 01 | Pengenalan R & Operasi Dasar | R sebagai alat analisis      |
| Praktikum 02 | Transformasi Data            | Logaritma & pangkat          |
| Praktikum 03 | Penanganan Data Hilang       | Missing data & imputasi      |
| Praktikum 04 | Analisis Regresi             | Eksplorasi, asumsi, validasi |

------------------------------------------------------------------------

## 🚀 Cara Menggunakan (Lokal)

### Prasyarat

-   R (≥ 4.2)
-   RStudio
-   Quarto

### Clone repositori

``` bash
git clone https://github.com/USERNAME/lab-interaktif-r.git
cd lab-interaktif-r
```

### Render

``` bash
quarto render
```
