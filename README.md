# Lab Interaktif R / Interactive R Lab

**Praktikum Analisis dan Visualisasi Data dengan Quarto / Data Analysis and Visualization Practicum with Quarto**

Repositori ini berisi rangkaian **praktikum R interaktif** yang dirancang menggunakan **Quarto**.
*This repository contains a series of **interactive R practicums** designed using **Quarto**.*

🔗 **Versi web / Web version:**\
https://avd.myprabowo.my.id\
https://muhammadyogaprabowo.quarto.pub/lab-interaktif-r

------------------------------------------------------------------------

## 🎯 Tujuan Pembelajaran / Learning Objectives

Setelah menyelesaikan seluruh rangkaian praktikum, peserta diharapkan mampu:
*After completing the entire practicum series, participants are expected to be able to:*

-   Menggunakan R untuk eksplorasi dan analisis data / *Use R for data exploration and analysis*
-   Memahami transformasi data dan dampaknya terhadap analisis / *Understand data transformation and its impact on analysis*
-   Menangani data hilang secara metodologis / *Handle missing data methodologically*
-   Melakukan analisis regresi secara eksploratif dan interpretatif / *Conduct exploratory and interpretative regression analysis*
-   Melakukan uji hipotesis formal pada analisis regresi cara konfirmasi / *Perform formal hypothesis testing in confirmatory regression analysis*
-   Melakukan pra-pemrosesan data teks, analisis frekuensi, n-gram, dan sentimen / *Perform text data preprocessing, frequency analysis, n-grams, and sentiment analysis*
-   Memvisualisasikan data teks menggunakan word cloud, network graph, dan heatmap / *Visualize text data using word clouds, network graphs, and heatmaps*
-   Membuat aplikasi visualisasi data reaktif dan interaktif menggunakan Shiny / *Create reactive and interactive data visualization applications using Shiny*
-   Membangun dan mendistribusikan dashboard interaktif dengan shinydashboard / *Build and distribute interactive dashboards with shinydashboard*

## 📂 Struktur Praktikum / Practicum Structure

| Praktikum / Practicum | Topik / Topic | Fokus Utama / Main Focus |
|--------------|------------------------------|------------------------------|
| Praktikum 01 | Pengenalan R & Operasi Dasar / *R Intro & Basic Ops* | R sebagai alat analisis / *R as an analytical tool* |
| Praktikum 02 | Transformasi Data / *Data Transformation* | Logaritma & pangkat / *Logarithms & powers* |
| Praktikum 03 | Penanganan Data Hilang / *Handling Missing Data* | Missing data & imputasi / *Missing data & imputation* |
| Praktikum 04 | Analisis Regresi Eksplorasi / *Exploratory Regression* | Eksplorasi, asumsi, validasi / *Exploration, assumptions, validation* |
| Praktikum 05 | Analisis Regresi Konfirmasi / *Confirmatory Regression* | Uji hipotesis, least squares, regresi berganda / *Hypothesis test, least squares, multiple regression* |
| Praktikum 06 | Analisis Data Teks / *Text Data Analysis* | Tokenisasi, stop words, frekuensi, sentimen / *Tokenization, stop words, frequency, sentiment* |
| Praktikum 07 | Visualisasi Data Teks / *Text Data Visualization* | Word cloud, bar plot, bigram network, heatmap / *Word cloud, bar plot, bigram network, heatmap* |
| Praktikum 08 | Visualisasi Interaktif / *Interactive Visualization* | Shiny layout (UI & Server), reaktivitas, input / *Shiny layout (UI & Server), reactivity, input* |
| Praktikum 09 | Dashboard Interaktif / *Interactive Dashboard* | shinydashboard, valueBox, tabItems, deploy / *shinydashboard, valueBox, tabItems, deploy* |

## 🚀 Cara Menggunakan (Lokal) / How to Use (Local)

### Prasyarat / Prerequisites

-   R (≥ 4.2)
-   RStudio
-   Quarto

### Clone repositori / Clone repository

``` bash
git clone https://github.com/myprabowo/lab-interaktif-r-avd.git
cd lab-interaktif-r-avd
```

### Render

``` bash
quarto render
```

## 🌐 Mode Interaktif (Quarto Pub) / Interactive Mode (Quarto Pub)

Tombol **Run Code** dijalankan menggunakan **webR (di browser)**.\
Tidak semua paket CRAN tersedia di webR, sehingga beberapa bagian lanjutan disarankan dijalankan secara lokal.
*The **Run Code** button is executed using **webR (in the browser)**.*\
*Not all CRAN packages are available in webR, so it is recommended to run some advanced sections locally.*
